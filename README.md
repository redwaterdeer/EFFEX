# EFFEX

사이트: https://redwaterdeer.github.io/EFFEX/

## GitHub Pages 업로드 (이 폴더 전체)

`EFFEX-main` 폴더 안의 아래 파일을 저장소 `redwaterdeer/EFFEX` **루트**에 그대로 올리면 됩니다.

| 파일 | 용도 |
|------|------|
| `index.html` | 메인 SPA (CSS·JS 포함) — **필수** |
| `app.js` | 로직 (보조) |
| `style.css` | PC 스타일 (보조) |
| `mobile.css` | 모바일 스타일 (보조) |
| `login.html` | 단독 로그인 페이지 |
| `schedule.html` | 일정 페이지 |
| `effex-sync.json` | 동기화 데이터 |
| `effex-sync-config.json` | 동기화 설정 |
| `README.md` | 설명 |

현재 운영 사이트는 주로 `index.html` 하나로 동작합니다.  
폴더 전체를 덮어쓰기 업로드하면 PC·모바일 모두 반영됩니다.
