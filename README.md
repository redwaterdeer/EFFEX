# EFFEX — GitHub 업로드용

사이트: https://redwaterdeer.github.io/EFFEX/

## 이 폴더의 파일 전부 업로드

아래 **9개 파일**을 GitHub 저장소 `redwaterdeer/EFFEX` **루트**에 그대로 덮어쓰기 하세요.

| 파일 | 비고 |
|------|------|
| `index.html` | **필수** (메인 SPA, CSS·JS 포함) |
| `app.js` | 로직 |
| `style.css` | PC 스타일 |
| `mobile.css` | 모바일 스타일 |
| `login.html` | 로그인 페이지 |
| `schedule.html` | 일정 페이지 |
| `effex-sync.json` | 동기화 데이터 |
| `effex-sync-config.json` | 동기화 설정 |
| `README.md` | 설명 |

## 업로드 방법

1. https://github.com/redwaterdeer/EFFEX 접속
2. 각 파일을 **Add file → Upload files** 로 올리거나, 폴더 전체 드래그
3. `Commit changes` 클릭
4. https://redwaterdeer.github.io/EFFEX/ 접속 후 확인 (캐시 있으면 강력 새로고침)
